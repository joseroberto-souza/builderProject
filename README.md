O padrão de projeto builder é um padrão criacional que serve para construir objetos complexos passo a passo.
Ele funciona como uma linha de montagem altamente personalizada dentro do desenvolvimento de software.
Com o uso desse padrão é possível reduzir o problema de construtores com muitos parâmetros.
A criação é flexivel, podendos criar diversas combinações dos parâmetros de forma implificada.
